# Egresos 14D1

Las columnas "No considerar es de Patrimonio Personal" se despliega solo cuando el contribuyente tiene el vector **Vx010042=1**, mientras que la columna "Facturas de Actividad de Renta Presunta" se despliega cuando el contribuyente tiene el **Atributo CRRP**.

Si Vx014022=1 .y. Vx014021>0 se despliega un mensaje indicando "Dado que registra facturas exentas o no gravadas, verifique si las operaciones por arriendos pagados fueron incluidas en dichos documentos y por tanto, registradas en el ítem "Compras y/o Servicios Sin derecho a Crédito Fiscal que digan relación con el giro del negocio (Cód. 521 + 560 + 562 del F29)", de ser así, correspondería restarlas en "Arriendos Pagados" para no duplicar dicho registro".

Si la celda de la columna B tiene valor 0 o vacío (y el contribuyente no puede complementar dicho valor) en las celdas de la columna C, D y E correspondientes a esa fila no se pueden ingresar datos.

Si no existen valores propuestos se debe desplegar la totalidad de las filas. En caso de existir valores propuestos se debe desplegar una pantalla customizada con las filas con valores distintos a cero (además de las filas de totalizadores 8). En la pantalla customizada siempre debe aparecer la opción desplegar la totalidad de las filas.
